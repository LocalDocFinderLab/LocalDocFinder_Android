## What's new in LocalDoc Finder 1.2.0

### Search
- **Faster, lighter search.** Searching no longer loads every chunk of your library into memory; it streams the stored vectors and keeps only the best matches, so it stays quick and steady as the index grows.
- **Better keyword ranking.** Keyword matches are now ordered by relevance (BM25) before the result limit is applied, so the best match is no longer lost when a word appears in hundreds of places.
- **Suggestions as you type.** Chips under the search box offer your past searches and matching file names; tap one to search for it.

### Reading a result
- **Similar documents.** The document reader lists the closest other documents (one per file, with a similarity score); tap one to open it.
- **Share an excerpt.** Share the matching passage with its file name and page, centred on the words you searched for.

### Library
- **Find Duplicates** (menu). Lists files whose indexed content is identical or nearly identical. It only reports; nothing is deleted.

### Development notes
- New `VectorScanner` (paged, bounded top-K vector scan), `SearchSuggestions`, `ShareFormatter`, `DuplicateFinder` and `UriNames`, all plain Kotlin with unit tests.
- New DAO queries (embedding/fingerprint pages, batched chunk and tag lookups, file-name and history suggestions). No schema change.
- Re-indexing with a new model now loads one file's chunks at a time.
