## What's new in LocalDoc Finder 1.3.0

### Models
- **The model sheet shows which model is actually running** ("Running now"). A model you picked but haven't downloaded yet is marked "Selected · not installed" and the built-in one keeps working until it arrives.
- **Switching models now offers to re-index straight away.** A dialog asks "Re-index with ...?" the moment the running model changes (picked, downloaded, imported or removed). Tap **Re-index now** and it happens on your phone; no more hunting for a button at the bottom of the sheet.

### Permissions and privacy
- **One up-front permission screen.** The app asks once for access to your files (and notifications), explains that nothing leaves your phone, and if you decline it says clearly that it can't work without it.
- **Privacy report** (menu): what the app has downloaded, how many requests it made, and that it uploaded nothing. This is enforced in code: every network call is HTTPS, download-only, and limited to Hugging Face (models) and GitHub (updates). Anything else is refused and counted.
- The match-quality chart in Filter & Sort no longer loads scripts from the internet; it is drawn on the phone.
- Removed the unused microphone permission.

### Regular and dev builds
- The regular app no longer shows sample documents, "Load 100 sample files", "Scan monitored folder", example queries or the benchmark tester.
- New **dev build** (`LocalDocFinder-v1.3.0-dev-<processor>.apk`, app name "LocalDoc Dev") for testing on devices. It installs next to the regular app and has a **Developer console**: network requests and bytes (compared with Android's own count for the app), app events and system log with copy/share, live app state, and the sample-data tools. It updates itself from the dev APKs only.

### Install
Download the APK for your phone from the release files. If unsure, use `LocalDocFinder-v1.3.0-arm64-v8a.apk`. For the dev build use `LocalDocFinder-v1.3.0-dev-arm64-v8a.apk`. Updating from 1.2.2 installs over the top.
