## What's new in LocalDoc Finder 1.1.0

### Search
- **Highlighted matches.** The words you searched for are shown in **bold** with a coloured background inside each result excerpt.
- **Persistent search bar and results list.** The search field stays on screen above a scrolling list of results from the on-device SQLite full-text index.

### Importing documents
- **File and folder picker.** Documents and folders chosen with the system picker are remembered in the app database (path, name, size, last modified) and can be reviewed under **Imported Documents** in the menu, where each shows *Pending*, *Indexed* or *Failed* and can be retried or removed.
- **Background indexing with PDFBox.** A WorkManager task reads each picked file with PDFBox, splits it into page-aware chunks and adds it to the full-text index. It keeps running when you leave the app and shows progress in a notification.

### Labels
- **Built-in labels:** Work, Personal, Finance, Legal, Medical, Education, Receipts, Travel, Research. Add your own too.
- **Filter by label.** Tap a label chip above the search results to show only documents carrying it.

### In the app
- A **What's New** dialog appears after installing or updating, and can be reopened from the menu.
- In-app update checks now point at this repository's releases and show these notes.

### Development notes
- Room database version 6 adds a `document_paths` table (migration 5 to 6, no data loss).
- New `PdfBoxIndexWorker` extracts text and writes document chunks; the external-content FTS4 table is kept in sync by Room triggers, and the index is optimised after bulk inserts.
- Default embedding model is BGE Small v1.5.
- Fixed a build error where the result list asked the highlighter for a bold option it did not expose.
- Release APKs are built by GitHub Actions (`.github/workflows/android-release.yml`) when a `v*` tag is pushed.

### Install
