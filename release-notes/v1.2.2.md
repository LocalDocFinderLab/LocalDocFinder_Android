## What's new in LocalDoc Finder 1.2.2

### Fixes
- **Large PDFs (20 MB and more) now index.** Files used to be given a flat 60 seconds, so big PDFs timed out twice and were skipped for good. The time allowed now grows with the file size, and a very long PDF keeps the pages that were read instead of failing.
- **The red "Quarantine Active" card can now be cleared.** When no crash is involved, its button reads **Retry Skipped Files** and puts the skipped files back in the queue. ("Dismiss Safe Mode" only appears while safe mode is actually on.)
- **Previews open much faster.** The preview now shows the text already stored in the index instead of reading the whole file again.
- **Previews scroll smoothly.** Long documents are shown in short blocks instead of one huge block of text, which could freeze and get stuck.
- **"Open file" works for files from Downloads and scanned folders.** It used to fail with "Cannot open file directly". If no app can open a file, the message now says so.
- A problem saving your search history can no longer wipe out the results you just found.

### Updating
This is the first release signed with a permanent key. **Uninstall the old version once, then install this one.** Android requires this because earlier releases were signed with a different, temporary key, and uninstalling clears the index. After this, updates install over the top without uninstalling.

### Install
Download the APK for your phone from the release files. If unsure, use `LocalDocFinder-v1.2.2-arm64-v8a.apk`. Allow "install unknown apps" for your browser or file manager when asked.
