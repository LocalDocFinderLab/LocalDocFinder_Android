## What's new in LocalDoc Finder 1.3.1

### Simpler for everyone
- **Simple search by default.** No more choosing between Hybrid, Vector and Keyword, or between six ways of indexing: the menu offers Scan My Phone, Choose a Folder, Pick Files and Added Folders & Files. Search balances exact words and meaning for each query.
- **Developer mode** (menu switch, off by default) keeps every engine option and indexing tool.
- **Better ranking:** question words (how, why, when...) no longer count as required words, words close together rank above scattered ones, and a file name typed with its extension is an exact match.

### Search
- **Suggestions as you type.** Chips under the search box offer your past searches and matching file names; tap one to search for it.

### Reading a result
- **Similar documents.** The document reader lists the closest other documents (one per file, with a similarity score); tap one to open it.
- **Share an excerpt.** Share the matching passage with its file name and page, centred on the words you searched for.

### Library
- **Find Duplicates** (menu). Lists files whose indexed content is identical or nearly identical. It only reports; nothing is deleted.

### Development notes
- New `VectorScanner` (paged, bounded top-K vector scan), `SearchSuggestions`, `ShareFormatter`, `DuplicateFinder` and `UriNames`, with unit tests. Merged on top of the 1.3.0 search ranker.
- New DAO queries (embedding/fingerprint pages, batched chunk and tag lookups, file-name suggestions). No schema change.

### Install
Download the APK for your phone from the release files. If unsure, use `LocalDocFinder-v1.3.1-arm64-v8a.apk`. Updating from 1.3.0 installs over the top.
