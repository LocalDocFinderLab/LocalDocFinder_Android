## What's new in LocalDoc Finder 1.3.2

### Fixes
- **One bad file no longer stops everything.** If a single document crashes or times out while indexing (for example a very large file), only that file is skipped. Automatic scanning keeps going for all your other files. Skipped files are listed in the menu, where you can retry them.
- **Large files that time out are skipped right away** instead of being tried again and again.
- **"What's new" shows once.** It is marked as seen as soon as it appears, so a restart no longer brings it back.

### Development notes
- `FailedDocumentRegistry` no longer engages app-wide Safe Mode on an uncaught crash; it quarantines the in-flight file only and clears any stale Safe Mode flag at startup.
- Indexing timeouts are recorded as hard failures (immediate quarantine).
