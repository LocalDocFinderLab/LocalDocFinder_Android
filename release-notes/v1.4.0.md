## What's new in LocalDoc Finder 1.4.0

### New
- **Hardware info for everyone.** Menu → Hardware & Thermal HUD now shows a "This device" card with your processor (SoC), CPU cores and top speed, GPU name with OpenGL / Vulkan version, whether the GPU can speed up search, and your NPU / TPU (Google Tensor generations are recognised).
- **One Dev build for every phone.** The Dev build is now a single universal APK (`LocalDocFinder-<tag>-dev-universal.apk`). No more choosing a processor type; install it next to the regular app and try every feature.

### Development notes
- New `engine/DeviceHardwareInfo`; the Hardware & Thermal HUD menu entry is no longer dev-only.
- Release workflow publishes only the universal dev APK.
