# v2.0.1

- **Search / Chat tabs** under the top bar. The side drawer follows the selected mode: sort options in Search, chat model / mobile-data / clear-conversation settings in Chat.
- **Chat needs indexing first**: until at least one file is indexed, the Chat tab says "Set up indexing first" and links to the indexing options.
- **Model downloads**: a download that keeps retrying now shows the last error (for example an HTTP status) instead of only "retrying", so failures can be diagnosed.
