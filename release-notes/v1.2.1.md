## What's new in LocalDoc Finder 1.2.1

### Much smaller download
- **One APK per phone type.** Each release now has a separate APK for each processor type, so your phone only downloads the code it can run. Pick the file for your phone:

  | File | For |
  |---|---|
  | `LocalDocFinder-v1.2.1-arm64-v8a.apk` | **Almost all phones from the last ~8 years. Use this one if unsure.** |
  | `LocalDocFinder-v1.2.1-armeabi-v7a.apk` | Older 32-bit phones |
  | `LocalDocFinder-v1.2.1-x86_64.apk` | Emulators and Chromebooks |
  | `LocalDocFinder-v1.2.1-universal.apk` | Any device (largest file) |

- **Unused code removed.** The app is now built as an optimised release build, which leaves out the parts of its libraries it never uses.
- **Updates pick the right file automatically.** From this version on, the in-app updater downloads the APK made for your phone's processor. Updating from 1.2.0 or 1.1.0 downloads the universal APK once.

Everything from 1.2.0 works the same: search, text in pictures, and Office files. Text recognition still runs entirely on your phone.

### Development notes
- Gradle ABI splits (`arm64-v8a`, `armeabi-v7a`, `x86_64`) plus a universal APK. 32-bit x86 is dropped (old emulators only).
- R8 shrinking is on for release builds with `-dontobfuscate` (class names kept, so reflection and stack traces keep working), plus keep rules for the app, ML Kit, TensorFlow Lite, PDFBox and Room.
- CI always builds the release variant. It is signed with your key when the `KEYSTORE_BASE64` / `STORE_PASSWORD` / `KEY_PASSWORD` secrets are set, otherwise with a temporary debug key.
- New CI job: a smoke test installs the shrunk x86_64 APK on an Android 14 emulator, lets the app index a text PDF, a scanned PDF and a photo, and checks that PDFBox and OCR worked and the app did not crash. Releases are only published when it passes.
- `ApkAssetChooser` picks the release asset from `Build.SUPPORTED_ABIS`, falling back to the universal APK. The universal APK is attached to the release first, so 1.1.0/1.2.0 (which take the first APK) also get a working file.

### Install
Download the APK for your phone from the table above and open it (allow "install unknown apps" for your browser or file manager when asked). If this release is signed with a different key than the version you have installed, Android asks you to uninstall the old version first, which also clears its index.
